# Cambodia checkout locations

Source: [Open Admin Data, Cambodia Administrative Divisions](https://github.com/open-admin-data/cambodia-administrative-divisions), retrieved 2026-10-21.
License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The original province, district and commune JSON files were reduced to codes, English/Khmer names and parent codes. Coordinates and postal codes are omitted. The upstream dataset reports an update date of 2026-09-08.

The Cambodia phone-prefix flag is from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Flag_of_Cambodia.svg), public domain / CC0. Stored separately as `static/assets/cambodia-flag.svg`.
